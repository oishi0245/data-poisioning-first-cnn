# Data Poisoning Attacks using CNN

## Research Topic
This repository contains my undergraduate research on Data Poisoning Attacks in Machine Learning using the CIFAR-10 dataset and Convolutional Neural Networks (CNN).

## Objective
To study how data poisoning attacks affect the performance of image classification models.

## Dataset
- CIFAR-10
- 60,000 RGB images
- Image Size: 32 × 32 pixels
- 10 Classes

## Technologies
- Python
- TensorFlow
- Google Colab
- GitHub
